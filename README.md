# Website Company Profile PT Indo Kreasi

Website company profile responsif menggunakan HTML, CSS, dan JavaScript.

## File
- `index.html` — struktur dan konten website
- `style.css` — desain dan tata letak responsif
- `script.js` — menu navigasi mobile dan tahun otomatis
- `assets/` — tempat menyimpan logo/gambar tambahan

## Menjalankan di laptop
1. Ekstrak ZIP.
2. Buka folder `pt-indo-kreasi` di VS Code.
3. Buka `index.html` di browser, atau gunakan ekstensi Live Server.

## Publikasi gratis melalui Netlify
1. Buka https://app.netlify.com/drop dan masuk/daftar.
2. Unggah folder website yang berisi `index.html`, `style.css`, dan `script.js` (jika Netlify meminta folder deploy, unggah folder tersebut atau ZIP yang sudah diekstrak sesuai petunjuk halaman).
3. Tunggu proses deploy selesai.
4. Atur nama situs dari pengaturan situs Netlify jika tersedia. URL gratis akan berbentuk `nama-situs.netlify.app`.

## Sebelum dipublikasikan
Konten layanan dan deskripsi perusahaan saat ini adalah contoh awal karena bidang usaha resmi, alamat, email, dan nomor telepon PT Indo Kreasi belum diberikan. Ganti semua konten contoh dengan informasi resmi. Tombol email juga perlu diperbarui pada `index.html`.
